How to save your schedule as XML
  1. In MS Project, open your schedule.
  2. File › Save As › choose “XML Format (*.xml)”.
  3. Drop the .xml file here.
Is my file safe?
  1. Test it yourself. Load this page, turn off your Wi-Fi, then check your file. It still works, because nothing goes to a server.
  2. Want to be extra careful? Save a copy, replace the activity names with codes, and check the copy. Every check still runs; the findings will show activity IDs instead of names.
  3. Not ready to use your own file? Try one of the sample schedules below first to see the kind of finding you get.
  4. No sign-up and no email. The report stays on your screen until you close the page.
